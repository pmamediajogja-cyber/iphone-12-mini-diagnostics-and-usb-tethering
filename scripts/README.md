# Scripts

Tempat untuk menaruh script asli yang telah diuji di PC Windows.

File yang disebutkan dalam riwayat proyek:
- `iphone_mode.py`
- `USB-Share.ps1`
- `Setup.ps1`
- `Uninstall.ps1`

**Belum disertakan pada paket awal** karena isi sumber asli tidak tersedia untuk diverifikasi pada saat dokumentasi dibuat. Jangan menggunakan file placeholder atau script buatan ulang sebagai pengganti. Salin file dari folder kerja asli, lalu lakukan review sebelum commit publik. Hapus credential, token, path pribadi, dan identifier perangkat.
